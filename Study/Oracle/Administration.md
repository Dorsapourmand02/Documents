
# **Managing database Instance


we have 2 parameter files:
1- Spfile 
2- Pfile

**SPFILE**
is written in the binary language and you can not change it manually the database use it to be open it contains all the database settings 


**PFILE**
is the spfile but in our language can change manually . kinda like backup so if the spfile would be crashed we could use it to recreate the spfile 


also we should remember that we always have backup from spfile
